# TAP Course Evaluation System

This Angular application is designed to evaluate online courses produced by Speccon Holdings. It features a clean, professional interface inspired by Speccon Holdings' branding, using a navy blue and white color scheme with card-based layouts.

## Features

- **Dashboard**: Overview of course statistics and list of available courses
- **Course Evaluation**: Detailed evaluation form with star ratings for multiple criteria
- **Responsive Design**: Mobile-friendly layout
- **Modern Angular**: Built with Angular 21, using signals, standalone components, and OnPush change detection

## Components

- Header: Navigation bar
- Dashboard: Main overview page
- Evaluate: Course evaluation form

## Styling

The application uses a custom theme matching Speccon Holdings' professional aesthetic:
- Primary color: Navy blue (#003366)
- Background: White
- Cards and borders: Light gray
- Typography: Roboto/Inter fonts
